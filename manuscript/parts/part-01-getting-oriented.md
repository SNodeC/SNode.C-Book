# Getting Oriented

Every later design decision in this book depends on a small set of shared terms. This first part builds that base before the framework becomes large: why SNode.C exists, what environment is needed, how the first echo pair runs.

By the end of the part, the echo pair should run, and the reader should be able to follow its public server type to the factory and context that supply its behavior. Part II will use that concrete path to distinguish configuration, activation, connection lifetime, and runtime dispatch more precisely.
