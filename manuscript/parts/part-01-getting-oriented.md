# Getting Oriented

Every later design decision starts from a program whose behavior the reader can follow. This first part establishes that concrete base: why SNode.C exists, what environment is needed, how the first echo pair runs.

By the end of the part, the echo pair should run, and the reader should be able to follow its public server type to the factory and context that supply its behavior. Part II will use that concrete path to distinguish configuration, activation, connection lifetime, and runtime dispatch more precisely.

The Part I checkpoint is Chapter 3’s greeting lab: send measurement-shaped bytes, check exact reflection and independent peers, and explain what the future MiniGateway still needs to accept a measurement.
