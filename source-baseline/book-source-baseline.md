# Book Source Baseline

This book describes SNode.C 2.0.0. Readers use `SNodeC/snode.c` master HEAD and
check its contents against the edition manifest before building.

`book-source-baseline.env` is the machine-readable authority; `SOURCE-VERSION.md`
documents cloning, updating and responding to drift. The manifest records 1,448
file contents and retains observed commit provenance as evidence only. The patch
file is empty and its digest is verified. No commit or tag is a checkout target.

The reviewed source includes asynchronous logging and semantic rendering on its
worker, together with the compiler's `-fno-gnu-unique` policy. Claim review and
build/runtime evidence are recorded in `review/pedagogical-smoothing-2026-09-23/`.
Earlier verification remains historical and is not relabeled as a current run.
